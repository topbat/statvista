## 1. 设计原则与设计令牌

### 1.1 五条设计原则（贯穿全部页面）

| # | 原则 | 落地要求 | 对应 DoD |
|---|------|---------|----------|
| P1 | **零输入、纯点击** | J1 五步全部动作为单击/悬停/右键；键盘输入仅出现在指标字典搜索框 | H3 |
| P2 | **元数据驱动渲染** | 箭头方向色、比较入口显隐、逆指标文案全部由指标元数据（agg_type / compare_policy / polarity）驱动，前端不写任何"某指标特殊处理"的硬编码分支 | D16 |
| P3 | **颜色只表方向** | 红/绿两色全域专用于涨/跌方向语义；分类色板、装饰、主题色一律不使用红绿，色弱用户靠"箭头+数值同显"可读 | D5 |
| P4 | **URL 即终态** | 下钻、联动、全局筛选终态全部压缩进 hash 查询串；刷新/分享/前进/后退逐级还原，不重放事件 | D12 |
| P5 | **三态必有兜底** | 任何数据区域必须实现加载/空/无权限三态；空数据必须区分"暂无数据"与"当前筛选下无数据"两种文案 | D17 |

### 1.2 色板（亮色政务风，CSS 变量表）

一次性写入 `styles/tokens.css`，全站唯一取色出口（页面样式禁止出现裸色值）。

```css
:root {
  /* ── 背景与容器 ─────────────────────────── */
  --bg-page:        #F5F7FA;   /* 页面底 */
  --bg-card:        #FFFFFF;   /* 卡片面 */
  --bg-hover:       #F0F5FF;   /* 可点行/图元 hover 底 */
  --bg-mask:        rgba(17,31,44,.35); /* 联动"变暗35%"用 */

  /* ── 边框 ──────────────────────────────── */
  --border:         #D9DEE8;   /* 卡片 1px 描边 */
  --border-strong:  #8C9BB5;   /* 强调描边（选中、线框） */

  /* ── 主色（政务蓝 #1677FF 系）──────────── */
  --primary:        #1677FF;
  --primary-hover:  #4096FF;
  --primary-active: #0958D9;
  --primary-bg:     #E6F4FF;   /* 选中底、全局筛选胶囊底、描边高亮底 */
  --primary-ring:   #1677FF;   /* 联动源图元描边高亮 2px */

  /* ── 文字 ──────────────────────────────── */
  --text-1:         #1F2329;   /* 标题、数值 */
  --text-2:         #4E5969;   /* 正文、轴标签 */
  --text-3:         #86909C;   /* 辅助说明（仅非关键信息，≥11px） */

  /* ── 方向语义色（红涨绿跌，专用，禁止挪用）─ */
  --up:             #D32029;   /* ▲ 涨/上升 */
  --down:           #08979C;   /* ▼ 跌/下降 */
  --flat:           #86909C;   /* ◇ 持平 */

  /* ── 警示语义色 ────────────────────────── */
  --alert:          #D4380D;   /* 逆指标变差、预警红 chip、排名垫底、明细表负增长行 */
  --alert-bg:       #FFF1F0;   /* 预警行底色 */
  --warn:           #D46B08;   /* 橙色预警 chip、cross-filter 胶囊 */
  --warn-bg:        #FFF7E6;

  /* ── 图表分类色板（8 色循环；刻意不含红绿，─
        使红绿专属涨跌语义不被干扰）            */
  --cat-1: #1677FF;  --cat-2: #13C2C2;  --cat-3: #722ED1;  --cat-4: #FA8C16;
  --cat-5: #F759AB;  --cat-6: #36CFC9;  --cat-7: #597EF7;  --cat-8: #FFC53D;

  /* ── 骨架屏 ────────────────────────────── */
  --skeleton: linear-gradient(90deg,#F2F3F5 25%,#E8EAEE 37%,#F2F3F5 63%);
  --skeleton-size: 400% 100%;
}
```

取色规则：

1. **红涨绿跌铁律**（设计方案 §3.3）：`▲` 恒配 `--up`、`▼` 恒配 `--down`，颜色只表数值方向；箭头、数值、单位必须同显，缺一不可（色弱可读）。持平用 `◇ --flat`。
2. **逆指标警示**：方向色规则不变（上升仍 `▲ --up`），警示语义通过 **卡片左侧 3px `--alert` 竖条 + 文案措辞**（"较上年上升 X pct"，禁写"增长/多增"）+ 指标名后缀 `(逆)` 体现，详见 §3.6。
3. **对比度**：正文文字对白底对比度 ≥ 4.5:1（`--text-1` 14.9:1，`--text-2` 7.0:1，`--up` 5.0:1，`--down` 4.6:1，均达标）；`--text-3` 仅用于轴标签、脚注等非关键信息。
4. **联动视觉三件套**专用色：源图元描边 `--primary-ring`；被过滤未命中数据加 `opacity:.65; filter:saturate(.6)`（即"变暗 35%+去饱和"）；漏斗角标 `--warn`。

### 1.3 字号层级

| 层级 | token | 值/字重 | 用途 |
|------|-------|--------|------|
| H1 | --fs-title | 20px / 600 | 页面主标题（驾驶舱名、看板名） |
| H2 | --fs-card-title | 14px / 600 | 卡片标题（ChartCard/AlertList 标题行） |
| 数值 | --fs-metric | 24px / 600，`tabular-nums` | 指标卡当期值（≥1600px 屏可 28px） |
| 正文 | --fs-body | 13px / 400 | 表格单元格、详情正文 |
| 小字 | --fs-caption | 12px / 400 | 指标卡名称、同环比行、胶囊 |
| 辅助 | --fs-axis | 11px / 400 | 图表轴标签、脚注、chip（**全站最小字号**） |

行高：正文 1.5；数值 1.2。数字一律 `font-variant-numeric: tabular-nums`（表格列、指标卡数值对齐）。

### 1.4 中文字体栈（离线可用，零 webfont）

```css

               "Microsoft YaHei", "PingFang SC", "Source Han Sans SC",
               "Noto Sans CJK SC", sans-serif;

```

说明：演示环境为 Windows 政务内网笔记本，实际命中 Microsoft YaHei UI；数字栈优先 Bahnschrift/DIN 只在存在时增强，不存在则回退，**不引入任何外部字体文件**（零构建约束）。适老化字号开关（+30%）归 P1，P0 不做（PRD §7-1 同源决策）。

### 1.5 间距、圆角、阴影、动效令牌

| token | 值 | 用途 |
|-------|----|------|
| --space-1 / 2 / 3 / 4 | 4 / 8 / 12 / 16 px | 4px 栅格；卡片内边距 12，卡片间距 12，分区间距 16 |
| --radius | 4px | 卡片、胶囊外框（政务风偏方正，禁大圆角） |
| --radius-pill | 999px | 胶囊、chip |
| --shadow-card | `0 1px 2px rgba(17,31,44,.04)` | 卡片轻阴影 + 1px --border 描边 |
| --dur | 300ms（区间 300–500ms） | 全部状态变化过渡；禁止跳变（设计方案 §3.2）；ECharts `animationDuration:300` |
| --dur-skeleton | 1.2s | 骨架屏 shimmer 循环 |

布局技术：CSS Grid + flex，设计基准 1440×900，自适应区间 **1280–1920**（PRD §7-1）。<1440px 时指标卡带允许换行为 2 行 ×4 卡；图表行不换行只压缩。滚动条样式使用系统默认。

### 1.6 ECharts 统一缺省（本地 echarts.min.js）

所有图表初始化前套用如下公共 option 片段（建议做成 `charts/theme.js` 导出 `baseOption`，逐图表 merge）：

```js
export const baseOption = {
  color: ['#1677FF','#13C2C2','#722ED1','#FA8C16',

  animationDuration: 300,
  textStyle: { fontFamily: 'var(--font-sans)', color: '#4E5969' },
  axisLabel: { fontSize: 11, color: '#4E5969' },
  splitLine: { lineStyle: { color: '#E5EAF2' } },
  tooltip: { backgroundColor:'#FFFFFF', borderColor:'#D9DEE8',
             borderWidth:1, textStyle:{ color:'#1F2329', fontSize:12 },
             extraCssText:'box-shadow:0 2px 8px rgba(17,31,44,.10);' }

```

地图职责替代（PRD §7-5）：**不引入任何 GeoJSON/地图组件**，省级排名 = 水平条形图；点击条形与点击地图省图元发同一 `drill:nav` 事件、写同一下钻状态、产同一 URL 终态，机制完全等价。

## 3. 交互细则

### 3.1 下钻（drill:nav）

**状态模型**：看板级按维度维护两条**下钻路径栈**——`regionStack`（全国→省→市，最深 2 级）与 `industryStack`（全行业→门类→大类，最深 2 级），PRD §2.1 冻结。每张 ChartCard 声明自己绑定的维度与粒度（可含本图私有粒度覆盖，如 C2 的 [门类|大类] 切换），订阅对应栈变化重取数。

**三入口同一事件**（D13，设计方案 §3.1）：

| 入口 | 位置 | 触发 |
|------|------|------|
| ① 点击图元 | 排名条形 / 趋势图图元 / 明细表行 | 鼠标单击 |
| ② 面包屑 | BreadcrumbNav 任意非末级节点 | 鼠标单击（=上钻，见 §3.2） |
| ③ 维度树侧栏 | region / industry 层级树节点 | 鼠标单击 |

三种入口发出**同一** `drill:nav` 事件、产生同一状态迁移与同一 URL 终态。

**下钻时序**（点击图元 → 入栈 → 面包屑 → URL → 重取数）：

```
用户单击"江苏"条形
 → ChartCard dispatch drill:nav {dim:'region', value:'320000', toLevel:'city', source:'cockpit-rank'}
 → state.js: regionStack.push({code:'320000', label:'江苏', level:'prov'})
    （驾驶舱无栈容器，此事件同时触发路由跳转 #/theme/macro?r=320000&rg=city）
 → BreadcrumbNav 重渲染: 全国 › 江苏
 → state.serialize() → history.pushState(hash)   ← 浏览器历史+1，后退=逐级上钻（D12）
 → 订阅 regionStack 的 ChartCard 以
    filters:[{dim:'region',op:'descendantOf',value:'320000'}] +
    granularity:'city' 重发 DSL 查询
 → 300ms 过渡：图表淡出旧值/淡入新值，禁止白屏跳变
```

**规则**：

1. 叶子节点（市级、大类）点击不发出 drill:nav，转为"查看明细"入口（§3.7）。
2. 一次下钻只操作一条栈；另一维度栈**不受影响、不清空**（"切换维度时原维度降级保留为过滤上下文"，体现在 URL 中两维度参数并存：`?r=320000&i=C`）。
3. 下钻 × 联动共存：下钻栈保留，最终 WHERE = `RLS ∩ 全局筛选 ∩ Σ cross-filter ∩ 下钻等值条件`，仅重算数据（设计方案 §3.2 冲突矩阵）。
4. 驾驶舱是下钻的"发射台"：C/D 区点击即跳主题看板并携带终态参数，驾驶舱自身不驻留下钻栈。

### 3.2 上钻（面包屑点击）

面包屑按维度分段渲染，段间以 `│` 分隔，段内节点间 `›`：`全国 › 江苏 │ 行业 › 制造业`。

- **末级节点**（当前层）：高亮 `--primary`，不可点击。
- **非末级节点**：可点击，hover 显下划线 + tooltip"回到此级"；点击发 `drill:nav {dim, value:'<该节点code>', toLevel:'<该节点level之下一级>'}`，state.js 将该维度栈**弹出至该节点**（目标节点成为新的末级）。
- 点"全国"根节点 = 该维度栈清空回到根。
- 上钻同样 pushState（前进可回到更深层级），与浏览器后退行为对称（D12）。

### 3.3 联动（cross-filter 事件总线）

**协议**（pub/sub，看板内广播，消息幂等，命名与设计方案 §3.2、T03 契约一致）：

```json
{ "type": "filter:click", "source": "chart-industry-donut",
  "payload": { "dim": "industry", "values": ["C"], "op": "in" } }
```

**流程**：单击 C1 环形图"制造业"扇区 →

1. 源扇区描边高亮 2px `--primary-ring`（ECharts `itemStyle.borderColor/borderWidth`）。
2. 总线广播 `filter:click`；订阅图表（C2/C3/指标卡带）把 `{dim:'industry',op:'in',values:['C']}` 并入查询 filters 重取数。
3. 被过滤图表中**未命中**数据项：`opacity:.65 + saturate(.6)`（视觉即"变暗 35%"），图表右上角出现**漏斗角标**（14×14 三角，`--warn`），悬停角标 tooltip"来自：行业构成图"。
4. 面包屑行出现橙胶囊 `行业=制造业 ×`（FilterPill kind=cross）；胶囊"×"删除该维度联动；胶囊区尾部出现**清除联动**按钮（仅存在 cross-filter 时显示），一键清空全板 cross-filter（下钻栈保留）。
5. 再单击已选中扇区 = 发 `filter:click {dim:'industry', values:[], op:'in'}`（空 values 语义为清除该维度的 cross-filter），取消联动。

**合成规则**（写死，D15 断言依据）：

| 情形 | 规则 |
|------|------|
| 同维度多次 filter:click | **last-wins**（后到覆盖，非并集） |
| 异维度 cross-filter | **AND 交集**（如 industry=C 且 region∈[320000,440000]） |
| cross-filter × 下钻栈 | 下钻栈保留，仅作为额外等值条件参与重算 |
| 全局筛选器变更 | **清空全部图表 cross-filter 栈**（§3.4） |
| 总 WHERE | `RLS ∩ 全局筛选 ∩ Σ cross-filter ∩ 下钻等值条件`（RLS 编译期注入，前端不可见不可传） |

### 3.4 全局筛选器变更 → 清空联动

时间范围 / 地区 / 行业任一全局筛选器变更（`change` 事件）：

1. 发 `global:change {dim:'time'|'region'|'industry', value, source:'filter-band'}`。
2. **立即清空全板 cross-filter**（橙胶囊全部消失、漏斗角标消失、源图元高亮解除）——上下文失效，语义无歧义（D15③）。
3. 下钻栈**保留**，仅以新全局筛选重算数据（下钻是导航语义，筛选是口径语义，二者不同生命周期）。
4. 蓝胶囊（global pill）更新为最新值；URL 的 `tf` / 全局筛选参数同步 pushState。

### 3.5 三态规范（每个数据区域必须实现）

| 状态 | 触发 | 视觉 | 文案与动作 |
|------|------|------|-----------|
| **加载中** | 查询发出未返回 | 骨架屏：卡片同构型的灰块（指标卡=名称条+数值大块；图表=标题条+280px 图形区整块），`--skeleton` 渐变 1.2s 循环 | 超 3s 叠加居中文字"正在加载…"（D17）；ECharts 不初始化，数据到位再 init + 300ms 入场 |
| **空数据 A：暂无数据** | 查询成功、该指标在任何条件下都无行（如字典新注册指标尚无种子） | 图表区居中 `--text-3` 插画位（40px 虚线圆+文档图标占位） | "暂无数据"+ 小字"更新频率：月（数据入库后自动出现）"；**无**清除按钮 |
| **空数据 B：当前筛选下无数据** | 查询成功返回 0 行、但去掉筛选有数据（联动/下钻过深；prov-js 显式过滤他省亦返回空集，D7） | 同 A 占位，但主色不同：图标 `--warn` | "当前筛选下无数据"+ 主按钮"清除筛选"→ 发 `filter:clear {scope:'all'}`（保留下钻栈） |
| **无权限** | 资源被 RLS 整体拒绝（P0 两角色对 3 页面均可见，此态为规范完整性预留，P1 受限看板启用） | 图表区居中锁形图标（24px `--text-3`） | "暂无权限查看该数据"+ 次按钮"申请权限"；**不暴露数据是否存在**（无行数、无指标名以外的信息） |

判定顺序：加载 →（响应到达）→ 无权限？ → 空 A/B 判定 → 正常渲染。空 A/B 的区分由语义层响应 `meta.emptyReason: 'no-data' | 'filtered-empty'` 提供（**T03 对齐点 A-2**：建议响应 meta 增加该字段；前端不自行猜测）。

### 3.6 红涨绿跌与逆指标（D5 断言规范）

**正指标（polarity=positive）**：

```
同比  ▲ 5.2%     → <span class="delta up">▲ 5.2%</span>，▲=--up #D32029
同比  ▼ 1.8%     → ▼ 配 --down #08979C
同比  ◇ 0.0%     → ◇ 配 --flat，文案"持平"
```

**铁律**：箭头、数值（含 %/pct/单位）必须同显；颜色只表方向，禁止只用色块/只箭头不数值。`▲▼◇` 使用文本字符（全平台字体自带，色弱靠形状区分）。

**逆指标（polarity=inverse，如 #10 能耗强度）**：

| 要素 | 规则 |
|------|------|
| 箭头与色 | 方向色规则**不变**：值上升 `▲ --up`、下降 `▼ --down`（颜色只表方向） |
| 文案 | 上升（变差）时禁写"增长/多增"，写 **"较上年上升 1.1pct"**；下降（变好）写"较上年下降 0.8pct" |
| 卡片警示 | MetricCard 左侧 3px `--alert` 竖条；指标名后缀 `(逆)`，12px `--warn` |
| 提示 | 卡片悬停 tooltip："逆指标：数值上升为变差。口径见指标字典。" + "查看字典"链接 → `#/dict?q=<编码>` |
| 环比 | 禁环比指标（compare_policy=禁环比/快照）整个环比行不渲染（D4②：入口置灰隐藏而非报错） |

**compare_policy → UI 映射**（元数据驱动，D16：新增 inverse 指标零代码自动生效）：

| compare_policy | 同比入口 | 环比入口 | 备注 |
|----------------|---------|---------|------|
| 直接比较 | 显示 | 显示 | sum 类 |
| compare_then_compute | 显示 | 显示 | 比值类，语义层先比分母分子 |
| 禁环比（cumulative） | 显示 | **不渲染** | 投资累计、就业累计、R&D 经费 |
| 快照同比（snapshot） | 显示 | **不渲染** | 研发人员全时当量 |

### 3.7 右键"查看明细"（drill-to-detail）

所有聚合图元（柱/条/扇区/折线点）与明细表行支持右键 → 上下文菜单（原生 `contextmenu` 拦截）：

```
菜单项：查看明细（唯一项）

                    timeRange:['2026-01','2026-10'], source:'chart-trend'}
 → 明细抽屉（右侧 420px 浮层）打开：该维度值 × 所选指标 逐月明细行
   （月份/当期值/同比/环比），负增长月份 --alert 红 + 行底 --alert-bg；
   表底口径脚注：`MACRO.IND.VA0002 · sum · 直接比较 · 责任处室：工业处`
```

### 3.8 事件协议总表（与 T03 契约对齐基准）

总线事件（bus.js 广播，`{type, source, payload}` 信封）：

| type | 方向 | payload | 备注 |
|------|------|---------|------|
| `drill:nav` | UI → state | `{dim:'region'\|'industry', value:'<code>', toLevel:'prov'\|'city'\|'c1'\|'c2', source}` | **命名沿用设计方案 §3.2，T03 契约同名**；下钻与上钻（面包屑）共用 |
| `filter:click` | UI → bus | `{dim, values:['<code>'...], op:'in', source}` | **命名沿用设计方案 §3.2，T03 契约同名**；values 用维度编码（GB/T 2260 区划码 / GB/T 4754 门类大类码），label 由字典翻译显示 |
| `drill:detail` | UI → 页面 | `{dim, value, metric, timeRange, source}` | **对齐点 A-1**：本规范新增命名，T03 若已定义同名事件以 T03 为准 |
| `global:change` | UI → 页面 | `{dim:'time'\|'region'\|'industry', value, source}` | 对齐点 A-1 同上；触发清空 cross-filter |
| `filter:clear` | UI → bus | `{scope:'all'\|'one', dim?, source}` | 同上；one=删单胶囊，all=一键清除/空态清除按钮 |

组件 DOM 事件（CustomEvent，bubble 出组件、不进总线）：`card:click`、`pill:remove`、`row:click` 等，见 §4 各组件；命名空间 `<组件名>:<动词>`，与总线事件（`drill:`/`filter:`/`global:` 前缀）严格区分。

## 4. 组件清单与命名（vanilla JS 直接实现）

### 4.0 实现形态约定（零构建约束下的组件化）

- **组件 = 浏览器原生 Web Components**（`customElements.define`，无依赖），一个组件一个文件，置于 `components/` 目录，页面以 ES Module 静态 import。
- **属性**：字符串属性用 attribute（`<metric-card code="...">`）；对象/数组属性用 DOM property（`el.trails = [...]`）。下表 props 列两种皆可传，内部约定 attribute 优先用于初始值、property 用于更新。
- **事件**：组件内 `this.dispatchEvent(new CustomEvent('drill:nav', {detail, bubbles:true, composed:true}))`；总线事件由页面控制器（`app.js`）监听组件 DOM 事件后经 `bus.js` 广播，组件不直接 import bus（单向依赖，便于单测）。
- **三态**：所有数据组件接受 `loading` / `empty-kind`（`'none'|'no-data'|'filtered-empty'|'no-perm'`）属性，按 §3.5 渲染。
- 共享模块：`bus.js`（on/emit/off，消息信封 `{type,source,payload}`）、`state.js`（栈管理+URL 编解码，见 §5）、`charts/theme.js`（§1.6 baseOption）、`api.js`（DSL POST 封装）。

### 4.1 `<metric-card>` MetricCard

指标卡：当期值 + 同比/环比 + 迷你趋势。用于驾驶舱 A 带、主题看板指标卡带。

| prop | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 注册指标编码，如 `MACRO.GDP.VA0001` |
| name / unit | string | 是 | 显示名、单位（%｜亿元｜万人…，11px 后缀） |
| value | number\|null | 是 | 当期值；null 且非 loading → 空态 |
| yoy | `{value:number, dir:'up'\|'down'\|'flat'} \| null` | 是 | 同比；null=不显示同比行 |
| mom | 同 yoy | 否 | 环比；**null=整个环比行不渲染**（禁环比/快照指标，D4②） |
| polarity | `'positive'\|'inverse'` | 是 | inverse → 左 3px `--alert` 竖条 + 名后缀 `(逆)` + 文案"较上年上升/下降"（§3.6） |
| spark | number[] | 否 | 12 个月迷你趋势；≥2 点渲染 60×22 折线（`--text-3` 1px，末点 `--primary` 3px 实心） |
| loading | boolean | 否 | 骨架屏 |
| href | string | 否 | 点击跳转（默认 `#/theme/<domain>?m=<code>`） |

events：`card:click {code}`（点击整卡）。
尺寸：驾驶舱态 高 128–160px 自适应宽；看板态 高 96px（省略 spark）。
渲染示例：名称 12px → `1,284.5 亿元`（数值 24px `--font-num` tabular + 单位 11px）→ `▲ 5.2% 同比`（12px）→ `▲ 0.4% 环比`。

### 4.2 `<breadcrumb-nav>` BreadcrumbNav

分维度下钻路径导航（仅主题看板；驾驶舱用范围 chip 不用此组件）。

| prop | 类型 | 说明 |
|------|------|------|
| trails | `{dim:'region'\|'industry', nodes:[{code,label,level}][]}[]` | 每维度一条 trail；nodes[0] 恒为根（全国/全行业）。数组 property 传入 |
| active-dim | `'region'\|'industry'` | 当前焦点维度（末级节点 `--primary` 高亮） |

events：`drill:nav {dim, value:<节点code>, toLevel:<该节点下一级>, source:'breadcrumb'}`——点击任意**非末级**节点触发（=上钻到该级，§3.2）；末级节点不响应。
渲染：`全国 › 江苏 │ 行业 › 制造业`，段间 `│` 用 `--border-strong` 竖线 1px；节点 hover 下划线；节点间 `›` 用 `--text-3`。

### 4.3 `<filter-pill>` FilterPill

过滤胶囊：全局筛选（蓝）与图表联动（橙）分色显示，支持单个删。

| prop | 类型 | 说明 |
|------|------|------|
| kind | `'global'\|'cross'` | global=蓝（`--primary-bg` 底/`--primary` 字/边）；cross=橙（`--warn-bg` 底/`--warn` 字/边） |
| dim | string | 维度键：time/region/industry |
| label | string | 显示文案，如 `时间 2024-01~2026-10`、`行业=制造业` |
| values | string[] | 编码集合（tooltip 展开全量） |

events：`pill:remove {kind, dim}` → 控制器翻译为 `filter:clear {scope:'one', dim}`（cross）或重置该全局筛选（global）。
容器约定：胶囊区置于面包屑行右侧；存在 cross 胶囊时尾部渲染文字按钮"清除联动"（12px `--warn`，hover 加深）→ `filter:clear {scope:'all'}`。

### 4.4 `<chart-card>` ChartCard

图表容器（标题 + 工具行 + ECharts 画布 + 三态 + 漏斗角标），一切 ECharts 图的统一外壳。

| prop | 类型 | 说明 |
|------|------|------|
| id | string | 图表唯一标识，作为一切事件的 `source`（如 `cockpit-rank`、`chart-industry-donut`） |
| title / subtitle | string | 标题 14px；subtitle=口径短脚注 11px `--text-3`（如"口径：当月值 · 直接比较"） |
| type | `'bar'\|'bar-line'\|'donut'\|'line'` | 决定默认交互绑定（可点下钻/可发联动） |
| option | object | ECharts option（已 merge baseOption）；数据变更由页面重新赋值 |
| bind-dim | `'region'\|'industry'\|null` | 可下钻维度；null=不下钻（如驾驶舱趋势图） |
| granularity | `'prov'\|'city'\|'c1'\|'c2'` | 当前粒度（跟随订阅的下钻栈，或本图私有覆盖） |
| cross-filtered | boolean | 被联动命中 → 显示漏斗角标 |
| segmented | `{options:[{key,label}], value} \| null` | 标题右分段控件（B 区[当月｜累计]、C2[门类｜大类]）；变更发 `segment:change` |
| loading / empty-kind | — | §3.5 三态 |

events（全部 CustomEvent bubbles）：

- `drill:nav {dim, value, toLevel, source:id}`——可下钻图元（条形/柱/折线点/扇区按 bind-dim）单击时派发；叶子粒度图元不派发，转上下文菜单。
- `filter:click {dim, values:[code], op:'in', source:id}`——**donut 扇区单击**（联动唯一源，J1 第 4 步）；再点选中扇区派发 `values:[]`（清除）。
- `drill:detail {dim, value, metric, timeRange, source:id}`——图元右键"查看明细"（§3.7）。
- `segment:change {key, source:id}`——分段控件切换。

视觉细则：标题行 高 32px；漏斗角标=右上角 14px 直角三角形 `--warn` + 悬停 tooltip"来自：{源图表标题}"；源图元（本卡是联动发起者且当前选中）2px `--primary-ring` 描边；被过滤未命中数据项 `opacity:.65; filter:saturate(.6)`。

### 4.5 `<alert-list>` AlertList

异常预警滚动列表（驾驶舱 D 区；数据来自预埋异常，PRD §6 预置）。

| prop | 类型 | 说明 |
|------|------|------|
| items | `{id, metric, metricCode, region, regionCode, delta, deltaUnit:'pct', month:'2026-10', level:'red'\|'orange'\|'info'}[]` | level→chip：red=`--alert` 底白字；orange=`--warn-bg` 底 `--warn` 字；info=`--primary-bg` 底 `--primary` 字 |
| max-rows | number | 默认 8，超出内部滚动（列表固定高，不撑破底 25% 分区） |

events：`drill:nav {dim:'region', value:regionCode, toLevel:'city', source:'alert-list'}`——**行单击**；与排名条形图点击产同一事件同一 URL 终态（J1 第 3 步等价入口，D12）。
行结构：`[chip 级别] 指标名 · 省份 · 偏离 -1.8pct · 2026-10`，行高 36px，hover `--bg-hover`，行首 3px 级别色竖条。

### 4.6 `<drill-table>` DrillTable

可下钻明细表（主题看板 C3 省市明细、字典结果列表复用）。

| prop | 类型 | 说明 |
|------|------|------|
| columns | `{key, label, align:'left'\|'right', format:'number'\|'pct'\|'text', width?}[]` | number/pct 列右对齐 + tabular-nums |
| rows | `object[]` | 行数据；`row.__drill = {dim, value, toLevel}` 标记可下钻行 |
| drillable | boolean | true=行点击发 drill:nav（看板态）；false=纯展示（字典态，行点击发 row:select） |
| detail-able | boolean | true=行/图元右键"查看明细"发 drill:detail |
| footer-note | string | 表底口径脚注 11px `--text-3`：`{code} · {agg_type} · {compare_policy} · 责任处室：{owner}`（D16） |
| alert-rule | `{key:'yoy', op:'<', value:0} \| null` | 命中行 → `--alert-bg` 行底 + 左 3px `--alert` 竖条 + 该单元格数值 `--alert`（负增长标红，J1 第 5 步） |
| loading / empty-kind | — | §3.5 三态 |

events：`drill:nav {dim, value, toLevel, source:id}`（行点击）；`drill:detail {..., source:id}`（右键/行尾"明细"按钮）；`row:select {row}`（字典态选中）。
尺寸：表头 sticky，行高 36px，最大高度=所在分区，超出滚动；省/市名列固定左侧。

### 4.7 页面级辅助件（非核心契约，简单实现）

- `<page-header>`：高 48px，白底下边框。左：平台名（16px/600）；中：三入口 tab（驾驶舱/主题看板/指标字典，active=`--primary` 文字+2px 底边条）；右：身份切换器（`leader / prov-js / prov-gd` 三选一 select，切换即整页重取数，URL 不变）+ "缓存调试"按钮（浮层显示 meta.cache/耗时/版本 bump 按钮，D10/D11 演示用，默认收起）。

## 5. 页面路由与导航结构

### 5.1 路由表（hash 路由）

P0 采用 **hash 路由**（`#/...`）：零构建静态服务无需服务端 rewrite，`node server.js` 单入口即可承载全部路由与刷新直达。与 PRD §5.0 路径一一对应（PRD 路径为语义名，hash 为实现名）：

| 路由 | 对应 PRD 路径 | 页面 | 默认参数 |
|------|--------------|------|---------|
| `#/cockpit` | `/cockpit` | 领导驾驶舱 | 最新月、leader 全国（prov-* 自动 RLS 裁剪） |
| `#/theme/macro` `#/theme/tech` | `/topic/:domain` | 主题看板（同模板换 domain） | tf=全区间 2024-01~2026-10、根级下钻态 |
| `#/dict` | `/dictionary` | 指标字典 | 无 facet、无选中行 |

路由器实现（`router.js`）：监听 `hashchange` + `popstate` → 解析 hash → `state.decode()` 还原终态 → 渲染对应页面模块。`#/` 与未知 hash 重定向 `#/cockpit`。页面切换 = 销毁旧模块 DOM + 新模块挂载（单页存活，无 iframe）。

### 5.2 URL 终态参数表（D12：存终态，不存事件序列）

hash 查询串由 `state.js` 双向编解码；参数**全部可选**，缺省即默认态：

| 参数 | 含义 | 示例 | 写入时机 |
|------|------|------|---------|
| `r` | region 下钻节点编码（缺省=全国） | `r=320000` | drill:nav(region) / 面包屑上钻 |
| `rg` | region 当前粒度 | `rg=city` | 同上 |
| `i` | industry 下钻节点编码（缺省=全行业） | `i=C` | drill:nav(industry) |
| `ig` | industry 当前粒度 | `ig=c2` | 同上 |
| `cf` | cross-filter 栈：`dim:code(＋code…)`，多维度 `;` 分隔 | `cf=industry:C` | filter:click / filter:clear |
| `tf` | 时间范围（月区间，逗号分隔） | `tf=2024-01,2026-10` | 全局筛选变更 |
| `gf.r` / `gf.i` | 全局筛选器地区/行业（区别于下钻栈） | `gf.i=D` | 全局筛选变更 |
| `m` | 看板聚焦指标编码（指标卡/字典跳入） | `m=MACRO.IND.VA0002` | 卡片点击 / 字典"在看板中查看" |
| `q` | 字典搜索词 | `q=能耗` | 字典搜索框 |
| `dt` | 明细抽屉：`dim:code`（开合即增删参数） | `dt=region:320100` | drill:detail / 关闭抽屉 |
| `sel` | 字典选中行编码 | `sel=MACRO.ENGI.GR0009` | 字典行点击 |

编码规则：短键 + 维度编码原值；编解码为纯函数（`state.encode(view)→string`、`state.decode(string)→view`），生产迁移时平移复用（PRD §4.3）。**每次状态迁移 `history.pushState`**（replaceState 仅用于初始规范化），浏览器前进/后退逐级回退（D12）。

### 5.3 J1 五步 URL 演进（演示走查基准）

| 步 | 动作 | URL 终态 |
|----|------|---------|
| 1 | 打开驾驶舱 | `#/cockpit` |
| 2 | 悬停（零点击，URL 不变） | `#/cockpit` |
| 3 | 单击排名条形"江苏"（或 D 区预警行） | `#/theme/macro?r=320000&rg=city` |
| 4 | 单击环形图"制造业"扇区 | `#/theme/macro?r=320000&rg=city&cf=industry:C` |
| 5 | 右键"查看明细"（江苏×制造业某市） | `#/theme/macro?r=320000&rg=city&cf=industry:C&dt=region:320100` |

复制任一步 URL 新开标签 → 完整还原面包屑、图表层级、胶囊、明细表（D12）。后退一次 = 撤销最近一次迁移（如第 4 步后退回第 3 步，cross-filter 消失）。

### 5.4 导航结构（全局 IA）

```
page-header（三页面常驻）
 ├ 平台名（点击回 #/cockpit）
 ├ tab：驾驶舱 ｜ 主题看板 ｜ 指标字典        ← 当前页 active
 └ 右侧：身份切换器（leader/prov-js/prov-gd）· 缓存调试按钮

驾驶舱 ──(排名条形/预警行点击，携带终态)──▶ 主题看板
驾驶舱 ──(指标卡/主题入口卡点击)─────────▶ 主题看板(?m=)
主题看板 ──(面包屑/维度树)───────────────▶ 自身上下钻（URL 变化）
字典 ──("在看板中查看")──────────────────▶ 主题看板(?m=&sel=)
任意页 ◀──(浏览器后退/前进)──────────────▶ popstate 终态还原
```

身份切换：不改变 URL，仅触发整页重取数（RLS 由账号决定）；切换后下钻栈若超出权限范围（prov-js 下 `r=440000`）→ 清空该栈并提示"已按权限重置范围"（不泄露越权数据，D7 精神）。
