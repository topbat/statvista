## 3. 缺陷 / 观察项清单（只记不修，交总协调裁定 W4 是否带病铸版）

| 编号 | 严重级 | 描述 | 影响与建议 |
|---|---|---|---|
| BUG-T30-1 | 中（**已修复，本轮回归确认关闭**） | dash-macro 报告先前 404（前端导出按钮 dashboard 枚举与端点白名单未对齐） | T29 波次已修复；本轮 tests.js T30① 断言 200+「宏观经济主题看板」通过，报告页 bytes=10709 |
| OBS-T30-1 | 低（观察项，不违约） | `meta.execution.sqlHash` 在 local 后端绑定**本地方言 SQL** 文本（sha256(meta.sql)），与 `/api/v1/compile` 端 Doris SQL 及 cacheKey **不同源**（cacheKey=sha256(canonical 请求)）。契约 §7.2「meta.sql 兼容注记」下行为合规，但未来切 doris 后端时 sqlHash 语义随 backend 切换 | 对账/审计文档应明示「sqlHash=实际执行 SQL 的哈希」；跨端点 SQL 对账须经 compile 端独立取 Doris 全文 |
| OBS-T30-2 | 低（使用注记） | 暗色主题参数通道为 `location.search`（真实查询串），hash 内 `theme=dark`（如 `#/cockpit?…&theme=dark`）**不生效**；正确形态 `/?theme=dark#/cockpit?province=320000&rg=city` | 与契约 §5「?theme= URL 参数优先」字面一致，非缺陷；联调/演示脚本需按此形态拼接（本轮 UI 验收即用该形态） |
| ENV-T30-1 | 环境（非产品） | 验收期间本机 3000 端口被残留进程占用（EADDRINUSE，PID 30844，非本次起停），测试按任务书改用随机/指定端口 3987，测毕已清理 | 建议 W4 铸版前清理开发机残留 node 进程，避免下次验收误连旧实例 |

**阻断级缺陷：无。**
