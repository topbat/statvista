## 1. 领域模型 ER 简述

```
指标字典 metrics.json          维度树 dims.json
  Metric(16, 含 agg_type/         Dimension(region/industry/time)
  compare_policy/polarity/        节点 code/parent/level/path 物化
  formula.num/den)                      │
       │ formula 引用                   │ 冗余层级列（prov/c1 冗余进事实行）
       ▼                                ▼
  支撑原子 atomic_store   ──▶  事实数据 facts.json（唯一事实表，无 JOIN）
  (CPI水平/能耗量/发明专利        行 = 市 × 行业大类 × 月（或 市 × 月）
   + *_py 上年基值列)             vals{...} 存原子值，不存派生/比值结果
                                       │ RLS：path LIKE 前缀裁剪
                                       ▼
                              角色 roles.json（leader / prov-js / prov-gd）
```

核心约定（对齐设计方案 §2、PRD §2.5 DSL 冻结范围）：

- **事实表只存原子值**：sum 型直接存值；ratio 型只存分子/分母两个原子（含上年基值列 `*_py`），比值由语义层现算（D3 compare_then_compute 的数据基础）；cumulative 型存累计口径；snapshot 型存期末值。
- **只存叶子粒度**（市×大类×月），省/全国、门类值全部由上卷聚合派生，不落盘——不存在"汇总行与明细行不一致"问题，RLS 与下钻天然一致。
- **事实行冗余层级列**（`prov/city/c1/c2/month`），下钻 = 换 group by 列 + 加等值过滤，零 JOIN（设计方案 §3.1）。
- **编码即外键**：metrics.formula 的 num/den、roles.allowed_metrics、facts.vals 字段 ↔ metrics.atomic_store，全部可程序化校验。

## 2. metrics.json —— 指标字典（16 个）

### 2.1 字段语义

| 字段 | 取值 | 说明 |
|------|------|------|
| type | atomic / derived / composite | 原子（事实字段+聚合）/ 派生（原子+时间修饰：本年累计）/ 复合（多原子四则或跨期运算） |
| agg_type | sum / ratio / cumulative / snapshot | 聚合与上卷行为；ratio 上卷 = Σ分子/Σ分母 |
| compare_policy | window_sum / compare_then_compute / none | 三种比较策略（PRD"直接比较"→window_sum；"禁环比仅同比/快照同比"→none，见 meta.compare_policy_defs） |
| compare_ops | [yoy] 或 [yoy,mom] | 允许的比较算子；cumulative/snapshot 仅 yoy（D4：mom 请求 4xx、UI 入口置灰） |
| polarity | positive / negative | 逆指标（negative）按警示语义展示（D5） |
| formula.num/den | 指标编码 | ratio/composite 必填；`@py`=上年基值列，`ytd()`=本年累计窗口和 |
| dim_caps | region/industry/time 各自可用粒度 | 语义层据此校验 DSL 维度合法性 |

| 维度 | 结构 | 节点数 |

## 4. facts.json —— 事实数据

**行格式**（紧凑 JSON，rows 数组）：

```json
{"city":"320500","prov":"320000","c1":"C","c2":"39","month":"2026-06",
 "vals":{"gdp_va":177.62,"gdp_va_py":170.79,"ind_va":159.21,"trade_va":107.22,
         "eng_con":81.3,"eng_con_py":77,"inv_cu":712.42,"emp_cu":4.32,
         "rd_cu":31.46,"pat_va":3438,"pat_inv":1011,"hti_va":105.3,"rdp_sn":0.24}}
```

（真实行示例：苏州 × 计算机通信电子设备制造(39) × 2026-06）

- **行业行**（city×c2×month，4400 行）：13 个原子字段；`ind_va` 仅 c1=C 行存在，`hti_va` 仅 c2∈{39,64,65,73} 行存在——"字段缺失"即"该口径不适用"，查询按空集处理。
- **区域行**（city×month，c1/c2=null，440 行）：无行业口径的 4 个字段（cons_va/fin_va/cpi_lvl/cpi_lvl_py）。
- **上卷规则**：sum/cumulative/snapshot → Σ；ratio → Σ分子/Σ分母（任一层级一致）。省/全国值不落盘。
- **py 基值列**：`gdp_va_py / eng_con_py / cpi_lvl_py` = 上年同月值。2026 年各行的 py 与事实 2025 年行逐位相等（生成器自校验断言）；2025 年各行的 py 来自"虚拟 2024"（同一公式，不落盘）——因此 GR0001/IDX0003/GR0009 三个跨期比值在全部 22 个月均可计算。

## 5. 确定性生成算法（gen-facts.js）

**禁止一切非确定性源**：无 `Math.random`、无 `Date.now`、无外部状态；唯一随机源为字符串哈希：

```
fnv1a(key#salt)  → 32bit
rnd(key,salt)    = fnv1a(key + '#' + salt) mod 100000 / 100000   → [0,1)
jit(key,salt,amp)= 1 + (rnd − 0.5) × 2 × amp                     → ±amp 乘性扰动
key = 城市|大类|月份（区域行 = 城市|R|月份）
```

**量值公式**：`值 = cityW × indW × K(指标族) × 年度水平 × 季节因子(m) × jit(...)`

- 年度水平：2025=1；2024=1/(1+yoy25)；2026=1+yoy26（各指标族独立增速参数）。
- 季节因子：12 月表（春节低、岁末高），均值归一。
- 累计类（inv/emp/rd）：`cu(m) = Σ(1..m 月流量)`，内部全精度累加、落盘才取整（月度增量=cu(m)−cu(m−1)，存在 ≤0.1 舍入残差，属正常）。
- CPI 定基水平：自虚拟 2024-01 链式月环比（基准+城市差+季节正弦+月噪声），2026 同比约 +0.6%~+1.0%。
- 量级（全国 20 市合计，2026-10 前后）：GDP 月 ~9900 亿、社零月 ~1.44 万亿、财政收入月 ~2243 亿、能耗月 ~4165 万吨标准煤（单位 GDP 能耗 ≈0.42 吨标准煤/万元）、专利月 ~17 万件（发明占比 ~28%）、R&D 强度 ~3.1%、研发人员 ~12.9 万人年。

**重生成一致性**：`node mvp/tools/gen-facts.js` 连续两次输出 MD5 相同（已验证：`2011abca…58c`），任何环境重跑逐字节一致，黄金用例可复现。

## 8. 边界与已知限制（供 T03 语义层知悉）

1. **时间窗 22 个月**（派工单冻结 2025-01~2026-10，较 PRD §2.3 的 34 个月缩小）。缓解：GDP/能耗/CPI 三族已存 `*_py` 基值列，其跨期比值（GR0001/GR0009/IDX0003）22 个月全程可算；其余指标（社零、财政、专利、规上工业等）的同比仅 2026-01..10 可算（2025 年各月基期不在事实窗内，返回空同比），演示主月 2026-10 不受影响。
2. **CPI/排名上卷简化**：CPI 上级值 = Σ分子/Σ分母 的城市等权合成（真实为加权）；驾驶舱"31 省排名"在原型中为 5 省排名（种子范围），机制不变。
3. **单月单元格噪声**：个别非异常单元格同比可能偶然为负（±5~10% 哈希扰动所致，符合真实统计波动）；"异常省份"判定以省级聚合口径为准（自校验已断言江苏唯一转负）。
4. **累计列舍入残差**：cu(m)−cu(m−1) 与"当月流量"存在 ≤0.1 的舍入差，语义层做差值展示时需容差处理。
5. **roles 中 prov 账号可见市数**：每省仅 4 个种子市，排名表即 4 市排名（与 PRD D8 机制一致，粒度为种子范围差异）。
