StatVista · GitHub 开源发布授权

MVP 原型全量产出 → 公开仓库 → Pages 公网体验站 · 指挥中心战报流实时记录全程

1
创建 GitHub 令牌（即"登录"）

GitHub 已于 2021 年取消密码调用 API，令牌就是登录凭证。点击下方按钮直达创建页（已预填 repo 权限与备注）， 勾选 repo → Generate token → 复制 ghp_…。

2
粘贴令牌并验证账号
令牌仅驻内存用于本次发布，不落盘、不经第三方。
3
点击发布 · 全自动执行

验证通过后点击「开始发布」：创建公开仓库（默认名 statvista，可改）→ 单提交推送全部交付文件 → 设置中文简介与 20 个关键词 → 启用 Pages。进度实时显示，并同步到指挥中心。

已发布过？点下方按钮：增量同步本地全部更新 → 打最新版本标签 v0.1.1 → 创建 GitHub Release（附体验站离线包 zip）→ 补全 20 个关键词。

4
完成后获得

① 仓库地址 ② 中文一句话简介 ③ 20 个关键词（topics）④ 公网体验入口 https://你的用户名.github.io/statvista/（Pages 构建 1–3 分钟后生效）

📦 仓库地址 🌐 公网入口
安全说明：令牌仅在本页与发布请求中使用，不落盘、不经过任何第三方；发布完成后建议到 GitHub → Settings → Applications 删除该令牌。
